# World Ascension 路线图 / Roadmap

以下是未来可能探索的方向，不代表发布日期或功能承诺。

These are possible future directions, not release dates or feature commitments.

## 中文

- 让农业、工业和学术城市的差异更清楚，并保持真实资源投入与取舍。
- 改善国家面板、事件说明和长期世界中的性能表现。
- 在现有重建与教育改革之上增加少量有明确成本的国家选择。
- 继续改善建筑、图标与不同文明外观的一致性。
- 优先修复兼容性和存档问题，再决定新系统范围。

## English

- Make Agriculture, Industry, and Academic cities more distinct while retaining real resource costs and tradeoffs.
- Improve the National Panel, event explanations, and performance in long-running worlds.
- Add a small number of meaningful national choices on top of reconstruction and education reform.
- Improve visual consistency across buildings, icons, and civilization variants.
- Prioritize compatibility and save issues before expanding the feature set.
